## ✨ O que o site tem

| Seção | Conteúdo |
|---|---|
| 🌅 **Hero** | Chamada de conversão + prova social (4.9★, +12 mil pratos) |
| 🍽️ **Cardápio** | 4 destaques com fotografia e CTA de reserva |
| 🛏️ **Suítes** | Mirante · Família · Chalé Pôr do Sol (botões pré-selecionam o form) |
| 🍸 **Experiência** | Carta de coquetéis + banner pôr do sol |
| 🎉 **Eventos** | Aniversários e grupos no terraço |
| ⭐ **Avaliações** | Depoimentos com foto e estrelas |
| 📷 **Galeria** | Lightbox com navegação por setas e contador |
| 📝 **Reserva** | Formulário validado que envia tudo pronto pro **WhatsApp** |
| 🗺️ **Contato** | Mapa embedado, rota, telefone e e-mail |

## 🛠️ Funcionalidades

- ✅ 100% responsivo (mobile · tablet · desktop)
- ✅ Menu mobile com acessibilidade (`aria-expanded`, fecha com `Esc`)
- ✅ Lightbox navegável (← →, contador, fecha com `Esc`)
- ✅ Formulário com validação + resumo da pré-reserva + integração WhatsApp
- ✅ Botão voltar ao topo, reveal on scroll, link ativo na navegação
- ✅ SEO: meta tags, Open Graph, Twitter Card e dados estruturados (JSON-LD)
- ✅ Respeita `prefers-reduced-motion`

## 🎨 Design System

Inspirado na referência **Azure Terrace** — elegância litorânea ao pôr do sol.

| Token | Valor | Uso |
|---|---|---|
| `--cream` | `#FAF6EE` | Fundo |
| `--navy` | `#0E2E4E` | Títulos, botões, footer |
| `--gold` | `#C2A059` | Detalhes, CTAs, estrelas |
| Display | `Cormorant Garamond` | Títulos serifados |
| Script | `Great Vibes` | Subtítulos manuscritos |
| Body | `Jost` | Texto e navegação |

## 🚀 Como rodar local

É só abrir o arquivo — sem build, sem dependências:

```bash
# opção 1: duplo clique em index.html
# opção 2: servidor local
python -m http.server 8080
# → http://localhost:8080
```

## 🌐 Deploy

Publicado automaticamente com **GitHub Pages** a partir da branch `main`:

```bash
git add . && git commit -m "atualização" && git push
```
